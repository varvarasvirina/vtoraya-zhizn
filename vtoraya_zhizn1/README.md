# «Вторая жизнь» — многостраничный статический сайт

## Страницы
- `index.html` — главная;
- `needs.html` — каталог потребностей;
- `shelters.html` — список организаций;
- `shelter.html?id=1` — отдельная страница организации;
- `donor.html` — кабинет благотворителя;
- `fund.html` — демонстрационный кабинет фонда;
- `about.html` — о проекте и принципе работы.

## Запуск
Распакуйте архив и откройте `index.html` в браузере. Для разработки можно использовать VS Code + Live Server.

## Технологии
Чистые HTML, CSS, JavaScript. Без сервера и базы данных. Состояние хранится в localStorage текущего браузера.

## Действия
Поиск, фильтры, сортировка, резервирование количества, личный кабинет, создание запросов, подтверждение получения и отмена резерва.

## Сброс демонстрационных данных
В консоли браузера выполните:
`localStorage.removeItem("vtorayaZhiznMultiV1")`
Затем обновите страницу.

## Ограничения
Данные демонстрационные. Все изменения локальны, не синхронизируются с другими пользователями и устройствами. Кабинет фонда не защищён авторизацией и не предназначен для реальной работы с персональными данными.
